## 安装前先了解一个重点

稳如狗 Windows 版属于海外网络加速器、VPN 加速器、网络代理工具类软件。为了实现节点连接、Tun 模式和网络传输，安装或运行时可能需要：

- 注册后台 service 进程。
- 建立网络连接。
- 接管部分系统网络能力。
- 调整系统代理或网络路由状态。
- 维持后台连接。

这些行为对网络加速器来说是正常的，但部分国内杀毒软件、安全卫士、电脑管家可能比较敏感，可能出现误报、拦截、隔离或删除安装文件。

这不一定代表安装包有病毒。关键是确认安装包来自稳如狗官网。

## 第一步：从官网下载 Windows 安装包

打开稳如狗官网：

[https://www.wenrugou.net](https://www.wenrugou.net)

进入官网后，选择 Windows 版下载入口，等待安装包下载完成。

不建议从以下来源下载安装包：

- 陌生网盘。
- QQ 群或微信群转发文件。
- 第三方论坛附件。
- 来路不明的压缩包。
- 非官方改版安装包。
- 他人二次打包的软件。

下载海外网络加速器、AI 工具访问软件、VPN 加速器时，安装包来源非常重要。只要来源不可靠，就无法确认是不是官方版本。

## 第二步：下载后提示风险怎么办？

如果浏览器、Windows 系统或杀毒软件提示风险，先确认两个问题：

1. 是否从稳如狗官网下载。
2. 文件是否下载完整。

如果来源无误，你可以自行把安装包提交到 VirusTotal 等检测平台检查。确认没有异常后，再继续安装。

部分安全提示来自 Windows 对未知发布者、可执行文件、网络工具的常规提醒，不一定代表文件有问题。

## 第三步：把安装包加入信任区

如果你的电脑安装了 360 安全卫士、电脑管家、火绒或其他安全软件，建议先把下载好的安装包加入信任区。

安装包路径可能类似：

```text
D:\Download\稳如狗_2.1.0_x64-setup
```

不同安全软件的入口名称可能不同，一般叫：

- 信任区。
- 白名单。
- 允许列表。
- 排除项。
- 文件信任。
- 恢复并信任。

建议不要只点击“临时允许”，最好明确把安装包加入信任区。

## 第四步：运行安装程序

把安装包加入信任区后，双击运行安装程序。

如果 Windows 提示：

- Windows 已保护你的电脑。
- 未知发布者。
- 是否仍要运行。

请先确认安装包来自稳如狗官网。确认无误后，可以点击“更多信息”“仍要运行”或“允许”，继续安装。

## 第五步：安装完成后信任整个安装目录

这是 Windows 安装里非常重要的一步。

安装完成后，不仅要信任安装包，还建议把稳如狗安装目录加入杀毒软件信任区。

常见安装目录类似：

```text
C:\Program Files\稳如狗
```

请注意，建议把整个目录加入信任区，而不是只信任某一个 exe 文件。

稳如狗正常运行时可能包含：

- 前端 GUI 进程。
- 稳如狗后台 service 进程。
- WebView2 相关进程。
- 网络连接组件。

如果只信任安装包，但没有信任安装目录，后续可能出现软件被删除、打开后闪退、连接失败、后台 service 被拦截、用几天后突然无法连接等问题。

## 第六步：打开稳如狗 Windows 客户端

安装完成后，可以通过以下方式打开：

- 桌面图标。
- 开始菜单。
- 安装目录中的主程序。
- 系统托盘图标。

首次打开时，请耐心等待客户端初始化。如果界面没有立即显示，可以稍等几秒。

## 第七步：查看设备账号和会员状态

稳如狗不需要传统注册账号，也不需要手机号、邮箱、验证码和密码。

安装后，系统会根据当前设备生成设备账号。打开客户端后，可以查看：

- 当前设备账号。
- 会员状态。
- 套餐类型。
- 到期时间。
- 节点列表。
- 当前连接状态。

如果需要联系客服处理会员、付款或设备问题，设备账号非常重要。

## 第八步：使用智能优选连接

新手首次使用，建议直接选择智能优选节点。

操作流程：

1. 打开稳如狗。
2. 查看会员状态。
3. 选择智能优选。
4. 点击连接。
5. 等待连接成功。
6. 打开 Google、ChatGPT 或 YouTube 测试。

不要刚打开就频繁切换多个节点。先用智能优选测试基础访问，稳定后再决定是否切换。

## 安装后无法启动、闪退、只有托盘图标怎么办？

Windows 版可能依赖 WebView2 显示界面。如果你的系统禁用了或卸载了 WebView2，可能出现：

- 程序能启动但不显示界面。
- 点击托盘菜单没有反应。
- 打开后闪退。
- 只有托盘图标。

可以检查是否通过第三方软件禁用了 Edge 或 WebView2。如果 WebView2 被卸载，可以重新安装 WebView2 后再打开稳如狗。

详细说明可以查看：[https://www.wenrugou.net/windows-install-guide](https://www.wenrugou.net/windows-install-guide)。

## 之前能用，突然连接不上怎么办？

如果之前使用正常，后来突然不能连接，优先检查：

- 安装目录是否仍在杀毒软件信任区。
- 稳如狗 service 是否被隔离。
- 是否最近安装了新的安全软件。
- 是否系统更新后安全策略变化。
- 是否同时运行了其他代理工具。
- 是否需要重启电脑。

如果安装目录不在信任区，建议重新添加，然后从官网重新下载安装包并修复安装。

## Windows 安装完成后建议测试哪些网站？

连接成功后，可以测试：

- Google 是否能打开。
- ChatGPT 是否能进入。
- Claude、Gemini、Perplexity 是否能访问。
- YouTube 是否能播放视频。
- Gmail 是否能加载。
- Google Scholar 是否能检索。
- GitHub 或跨境办公网站是否能访问。

如果你主要使用 AI 工具，也可以查看稳如狗 AI 导航：[https://www.wenrugou.net/ai-navigation.html](https://www.wenrugou.net/ai-navigation.html)。
