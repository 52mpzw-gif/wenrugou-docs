# 第一次如何连接

如果你是第一次使用稳如狗，可以按本文完成首次连接。稳如狗支持 Windows 和 Android 客户端，适合访问 ChatGPT、Claude、Gemini、Perplexity、Google、YouTube、Gmail、Google Play、外服游戏、跨境办公和学术检索网站。

首次连接的目标很简单：打开客户端，确认账号和会员状态，选择智能优选节点，点击连接，然后测试 Google、ChatGPT 或 YouTube 是否能正常访问。

## 首次连接前需要准备什么？

开始前请确认：

- 已经安装稳如狗 Windows 或 Android 客户端。
- 设备本地网络正常。
- 客户端可以正常打开。
- 当前设备账号已经生成。
- 会员状态正常，或你了解当前套餐状态。
- Android 用户已准备允许系统连接权限。
- Windows 用户已处理杀毒软件信任区问题。

如果你还没有安装，可以先阅读：

- [Windows 下载安装教程](/guide/windows-install)
- [Android 下载安装教程](/guide/android-install)

## 第一步：打开稳如狗客户端

Windows 用户可以通过：

- 桌面图标。
- 开始菜单。
- 安装目录。
- 系统托盘。

Android 用户可以从手机桌面点击稳如狗 App 图标。

首次打开时，请耐心等待客户端初始化。如果 Windows 端打开后不显示界面，可能与 WebView2 或安全软件有关，可以参考 [https://www.wenrugou.net/windows-install-guide](https://www.wenrugou.net/windows-install-guide)。

## 第二步：查看设备账号和会员状态

稳如狗不需要手机号、邮箱、验证码和密码。打开客户端后，系统会自动识别当前设备账号。

你可以查看：

- 当前设备账号。
- 会员状态。
- 套餐类型。
- 到期时间。
- 节点列表。
- 当前连接状态。

如果你还没有会员，可以先查看套餐说明；如果已经付费但会员没有显示，可以等待 1 到 3 分钟后重启客户端，或联系客服并提供设备账号和付款截图。

## 第三步：选择智能优选节点

新用户首次连接，建议先使用智能优选节点。

智能优选适合大多数用户，因为系统会根据当前网络环境、节点状态、节点负载和使用场景，自动选择更适合的线路。

如果你不确定选哪个节点，不要一开始就手动乱选。先用智能优选测试基础访问。

## 第四步：点击连接

选择节点后，点击连接按钮。

连接过程中请等待几秒，不要频繁重复点击。连接成功后，客户端通常会显示：

- 已连接。
- 当前节点。
- 连接时长。
- 连接状态。

Android 手机首次连接时，系统会弹出连接权限确认，请点击允许。如果拒绝权限，稳如狗无法正常建立连接。

## 第五步：测试 Google

连接成功后，建议先打开 Google 测试基础海外访问。

如果 Google 能快速打开，说明基础连接通常已经正常。

如果 Google 打不开，可以尝试：

- 刷新网页。
- 关闭浏览器重新打开。
- 使用智能优选重新连接。
- 切换节点。
- 关闭其他代理工具。
- 清理浏览器缓存。

## 第六步：测试 ChatGPT 或其他 AI 工具

如果你主要使用 AI 工具，可以测试：

- ChatGPT 是否能打开。
- Claude 是否能登录。
- Gemini 是否能加载。
- Perplexity 是否能搜索。
- Cursor 或 GitHub Copilot 是否能正常连接。

重点观察：

- 页面是否一直转圈。
- 登录是否正常。
- 对话是否能发送。
- 回答是否中断。
- 文件上传是否正常。

常用 AI 工具入口可以查看稳如狗 AI 导航：[https://www.wenrugou.net/ai-navigation.html](https://www.wenrugou.net/ai-navigation.html)。

## 第七步：测试 YouTube 或 Google Play

如果你主要看视频，可以测试：

- YouTube 是否能打开。
- 视频是否能播放。
- 是否一直缓冲。
- 720P、1080P 是否流畅。
- 直播是否卡顿。

如果你主要使用 Android 手机，可以测试：

- Google Play 是否能打开。
- Gmail 是否能加载。
- Google App 是否能搜索。
- YouTube App 是否能播放。

连接成功后，如果 App 仍然打不开，建议完全关闭 App 后重新打开，必要时清理 App 缓存。

## 连接成功但网页打不开怎么办？

可以按下面顺序排查：

1. 刷新网页。
2. 关闭浏览器重新打开。
3. 使用无痕模式测试。
4. 清理浏览器缓存。
5. 切换节点。
6. 关闭其他代理工具。
7. 重启稳如狗客户端。
8. 重启设备。

Windows 用户还要检查杀毒软件是否拦截了稳如狗后台 service。Android 用户要检查系统连接权限和省电限制。

## 首次连接失败怎么办？

可以尝试：

- 检查本地网络。
- 使用智能优选重新连接。
- 切换其他节点。
- 确认会员状态。
- 重启客户端。
- 关闭其他代理工具。
- Windows 检查信任区。
- Android 检查连接权限。
- 重启设备。

如果仍然失败，可以查看 [连接失败排查指南](/support/connection-failed)。

## 新用户首次连接建议

建议按这个顺序：

1. 先用智能优选。
2. 连接成功后测试 Google。
3. 再测试 ChatGPT 或 YouTube。
4. 如果访问慢，再切换节点。
5. 找到稳定节点后，不要频繁切换。
6. 遇到问题先按帮助中心排查。

帮助中心地址：[https://www.wenrugou.net/help.html](https://www.wenrugou.net/help.html)

## 总结

第一次使用稳如狗，重点是不要复杂化：打开客户端，查看设备账号和会员状态，选择智能优选，点击连接，先测试 Google，再测试 ChatGPT、YouTube、Gmail 或 Google Play。当前节点稳定时，不建议频繁切换。
