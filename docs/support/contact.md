# 如何联系客服？

如果你在使用稳如狗加速器时遇到连接失败、会员未生效、设备账号不一致、Windows 杀毒软件拦截、Android 无法连接、ChatGPT 打不开、Google 打不开、YouTube 一直转圈等问题，可以先查看帮助中心，再联系客服处理。

稳如狗帮助中心地址是 [https://www.wenrugou.net/help.html](https://www.wenrugou.net/help.html)。如果你还没有安装客户端，建议先从官网 [https://www.wenrugou.net](https://www.wenrugou.net) 下载官方版本，避免使用非官方安装包导致问题更复杂。

## 什么情况建议联系客服？

下面这些情况适合联系客服：

- 付款成功，但客户端仍然显示非会员。
- 会员到期时间不对，套餐状态没有刷新。
- 换电脑、换手机、重装系统后会员不见了。
- Windows 和 Android 设备账号需要绑定或核对。
- 多个节点都连接失败。
- 连接成功但 Google、ChatGPT、YouTube 都打不开。
- Windows 安装包被 360、电脑管家等安全软件隔离。
- Android 已允许连接权限，但仍然无法连接。
- 反复排查后仍然无法判断原因。

如果只是单个网站临时打不开，例如只有 ChatGPT 打不开、只有 YouTube 卡顿，可以先按对应教程排查缓存、插件、节点和网站状态。

## 客服通常多久回复？

稳如狗提供在线客服支持，通常会在 24 小时内回复和处理用户问题。

白天 08:00 到 20:00 期间，反馈处理通常更快。晚上、节假日或问题较复杂时，可能需要等待更久。

为了减少来回沟通，建议第一次反馈时就把关键信息发完整。

## 联系客服前先准备哪些信息？

建议准备：

- 当前设备账号。
- 设备类型，Windows 还是 Android。
- 当前会员状态截图。
- 付款截图或订单信息。
- 付款时间和套餐类型。
- 当前使用的节点。
- 问题网站，例如 ChatGPT、Google、YouTube、Gmail。
- 错误提示截图。
- 是否安装 360、电脑管家、火绒等安全软件。
- 是否同时运行 Clash、其他 VPN、浏览器代理插件。

如果你只说“不能用”或“连不上”，客服还需要继续追问设备、账号、节点、截图等信息。把信息一次性发全，处理会快很多。

## 连接失败应该怎么描述？

连接失败类问题，建议说明清楚是哪一种：

| 表现 | 说明 |
| --- | --- |
| 点击连接后失败 | 可能是节点、本地网络、权限或后台服务问题 |
| 显示已连接但网页打不开 | 可能是浏览器缓存、代理冲突、DNS 或节点问题 |
| 只有 ChatGPT 打不开 | 可能是 AI 平台、账号、缓存、插件或节点适配问题 |
| Google、YouTube、ChatGPT 都打不开 | 更像整体海外访问链路或代理状态问题 |
| 付费后连不上 | 需要先确认会员状态，再排查连接环境 |

反馈时可以写成：“Windows 电脑，会员已显示，智能优选连接成功，但 Google 和 ChatGPT 都打不开，已关闭 Clash，安装了 360，截图如下。”这种描述比“连不上”更容易定位。

## 会员和设备账号问题怎么反馈？

稳如狗不需要手机号或邮箱注册。安装客户端后，系统会根据设备生成匿名设备账号，会员通常绑定当前设备账号。

如果是会员问题，请提供：

- 当前设备账号。
- 原设备账号，如果换过设备。
- 付款截图。
- 付款时间。
- 套餐类型。
- 当前客户端会员状态截图。
- 是否重装系统、重置手机、清理应用数据。

如果你在 Windows 端购买会员，后来想在 Android 端使用，也请提供两个设备的设备账号，方便客服核对绑定。

## Windows 问题怎么反馈？

Windows 用户常见问题包括安装包被删除、软件打不开、service 被拦截、连接失败、连接后网页打不开。

反馈时建议说明：

- 安装包是否来自官网。
- 是否安装 360、电脑管家、火绒等安全软件。
- 是否把安装包和安装目录加入信任区。
- 是否重启过电脑。
- 是否同时运行其他代理工具。
- 错误截图或安全软件拦截记录。

如果是 Windows 杀毒软件误拦截，可以先查看官方 Windows 安装指南：[https://www.wenrugou.net/windows-install-guide](https://www.wenrugou.net/windows-install-guide)。

## Android 问题怎么反馈？

Android 用户常见问题包括 APK 无法安装、未知来源提示、首次连接权限未允许、App 被系统省电限制、Google Play 或 YouTube 打不开。

反馈时建议说明：

- 手机品牌和系统版本。
- APK 是否来自官网。
- 是否允许未知来源安装。
- 首次连接时是否允许系统连接权限。
- 是否开启省电模式。
- 是否允许稳如狗后台运行。
- 使用 Wi-Fi 还是手机流量。

如果 Android 端显示已连接但 YouTube、Google Play 仍然打不开，可以尝试关闭 App 后重新打开，或清理 App 缓存后再反馈。

## AI 工具问题怎么反馈？

如果问题是 ChatGPT、Claude、Gemini、Perplexity、Cursor、GitHub Copilot 打不开，可以提供：

- 哪个 AI 工具打不开。
- 是页面空白、一直转圈、登录失败，还是回答中断。
- Google 是否能打开。
- 其他 AI 工具是否正常。
- 使用浏览器还是 App。
- 是否试过无痕模式。
- 是否安装广告拦截或脚本插件。

如果只是找不到 AI 工具入口，可以查看稳如狗 AI 导航 [https://www.wenrugou.net/ai-navigation.html](https://www.wenrugou.net/ai-navigation.html)。

## 联系客服前可以先做哪些自查？

建议先尝试：

1. 重启稳如狗客户端。
2. 使用智能优选重新连接。
3. 切换节点测试。
4. 重启浏览器或目标 App。
5. 清理浏览器缓存。
6. 关闭其他代理工具。
7. Windows 检查安全软件信任区。
8. Android 检查系统连接权限。
9. 查看帮助中心相关文章。

如果自查后仍然异常，再联系客服并带上截图，会更高效。

## 总结

联系客服时，最重要的是提供“设备账号 + 问题截图 + 具体场景”。稳如狗客服通常会在 24 小时内回复，白天处理更快。描述清楚设备、会员、节点、目标网站和错误表现，能显著减少沟通成本。
