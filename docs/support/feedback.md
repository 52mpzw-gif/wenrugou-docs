# 如何提交问题反馈？

提交问题反馈时，信息越完整，处理越快。很多“连接失败”“速度慢”“付费后不能用”“ChatGPT 打不开”“YouTube 一直转圈”的问题，如果只描述一句“用不了”，客服很难直接判断原因。

本文整理了稳如狗问题反馈建议。反馈前也可以先查看帮助中心 [https://www.wenrugou.net/help.html](https://www.wenrugou.net/help.html)，很多常见问题都有对应教程。

## 通用反馈模板

可以按下面模板整理：

```text
设备类型：Windows / Android
设备账号：
会员状态：非会员 / 周会员 / 月会员 / 季会员 / 年会员
当前节点：智能优选 / 具体节点名
问题类型：连接失败 / 速度慢 / 会员未生效 / 网站打不开 / 安装失败
问题网站：Google / ChatGPT / YouTube / Gmail / Google Play / 其他
具体表现：点击连接失败 / 显示已连接但网页打不开 / 一直转圈 / 回答中断
已尝试操作：重启客户端 / 切换节点 / 清理缓存 / 关闭其他代理 / 加入信任区
是否安装安全软件：360 / 电脑管家 / 火绒 / 无
截图：会员状态、错误提示、付款记录、拦截记录
```

你不一定每项都有，但设备账号、问题截图、具体表现最好提供。

## 连接失败反馈应该写什么？

连接失败请说明：

- 点击连接后是否直接失败。
- 是否显示连接成功。
- 连接成功后哪些网站打不开。
- 是否试过智能优选。
- 是否切换过其他节点。
- 国内网站是否正常。
- 是否同时运行其他代理工具。
- Windows 是否有杀毒软件。
- Android 是否允许连接权限。

示例：

```text
Windows 电脑，月会员已显示，使用智能优选点击连接失败。
国内网站正常，已关闭 Clash，安装了 360。
安全软件没有弹窗，但连接一直失败，截图如下。
```

## 速度慢反馈应该写什么？

速度慢请说明慢在哪里：

- Google 打开慢。
- YouTube 1080P 卡顿。
- YouTube 4K 加载慢。
- ChatGPT 回答慢。
- Claude 页面一直转圈。
- Google Play 下载慢。
- 外服游戏延迟高。

同时说明：

- 当前节点。
- 慢的时间段。
- 是否晚高峰。
- 是否关闭后台下载。
- 是否多个网站都慢。
- 是否换节点测试。

示例：

```text
Android 手机，智能优选已连接。
Google 能打开，但 YouTube 1080P 一直缓冲，720P 正常。
晚上 10 点左右更明显，已关闭后台下载。
```

## 会员未生效反馈应该写什么？

会员问题请提供：

- 当前设备账号。
- 付款截图。
- 付款时间。
- 付款金额。
- 套餐类型。
- 客户端会员状态截图。
- 是否换设备、重装系统、清理应用数据。

示例：

```text
Windows 端购买月会员，付款成功后客户端仍显示非会员。
当前设备账号是 XXX，付款时间是 XX:XX，付款截图如下。
已经重启客户端，状态仍未刷新。
```

稳如狗会员通常绑定当前设备账号，所以设备账号非常重要。

## Windows 杀毒软件问题反馈应该写什么？

Windows 安全软件误拦截，请提供：

- Windows 版本。
- 安全软件名称，360、电脑管家、火绒或其他。
- 安装包是否来自官网。
- 拦截截图。
- 隔离区截图。
- 是否已经加入信任区。
- 是否信任整个安装目录。
- 当前连接表现。

如果你还没看 Windows 安装指南，建议先看：[https://www.wenrugou.net/windows-install-guide](https://www.wenrugou.net/windows-install-guide)。

示例：

```text
Windows 11，安装包来自官网。
360 提示风险并隔离了稳如狗 service，已恢复但仍连接失败。
安装目录已加入信任区，拦截图如下。
```

## Android 问题反馈应该写什么？

Android 问题请提供：

- 手机品牌和系统版本。
- APK 是否来自官网。
- 是否允许未知来源安装。
- 是否允许系统连接权限。
- 是否关闭省电限制。
- 是否允许后台运行。
- 使用 Wi-Fi 还是手机流量。
- 具体打不开的网站或 App。

示例：

```text
小米手机，Android 版本 XX。
已允许系统连接权限，智能优选显示已连接。
Google 能打开，但 Google Play 一直等待下载，已重启 App。
```

## AI 工具问题反馈应该写什么？

AI 工具问题请提供：

- 哪个工具打不开，ChatGPT、Claude、Gemini、Perplexity、Cursor、GitHub Copilot。
- 是打不开首页、登录失败、一直转圈，还是回答中断。
- Google 是否能打开。
- 其他 AI 工具是否能打开。
- 浏览器还是 App。
- 是否试过无痕模式。
- 是否安装广告拦截、脚本插件。

AI 工具入口可以查看稳如狗 AI 导航：[https://www.wenrugou.net/ai-navigation.html](https://www.wenrugou.net/ai-navigation.html)。

## 反馈时最好附截图

建议附这些截图：

- 设备账号截图。
- 会员状态截图。
- 错误提示截图。
- 付款截图。
- 安全软件拦截图。
- 目标网站打不开的截图。
- 节点连接状态截图。

截图可以减少误解，比文字描述更直观。

## 反馈前建议先做的操作

提交反馈前，可以先尝试：

1. 重启稳如狗客户端。
2. 使用智能优选。
3. 切换节点测试。
4. 重启浏览器或目标 App。
5. 清理缓存。
6. 关闭其他代理工具。
7. Windows 加入安全软件信任区。
8. Android 检查连接权限。

如果这些都试过，请在反馈里说明，客服就不会重复让你做同样操作。

## 总结

好的问题反馈应该包括设备、账号、会员、节点、目标网站、错误表现、截图和已尝试操作。稳如狗客服通常会在 24 小时内处理，信息越完整，处理越快。
